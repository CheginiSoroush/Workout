# داشبورد فیتنس من — برنامه «شناگر» (FST-7)

## دربارهٔ پروژه

این داشبورد برای خودم ساخته شده — برنامهٔ ۳ روزهٔ Push / Pull / Legs با
FST-7 در پایان هر جلسه، RPE ۸–۹ و پیشروی دوگانه. همه‌چیز داخل آن است:

- 🏋️ **برنامهٔ تمرین** — ۲۰ حرکت با ویدیو/فلیپ‌بوک، نکات فرم، خطاهای رایج و نسخهٔ دستگاه ↔ وزنهٔ آزاد
- 📋 **ثبت جلسه** — ثبت ست‌به‌ست وزنه و تکرار، استراحت‌سنج و RPE
- 📈 **پیشرفت** — نمودار وزنه، استمراری هفتگی و رکوردهای شخصی
- 🧪 **دانش و منابع** — قاموس ۳۱ اصطلاحی، کراتین، CLA، پژوهش‌ها و منابع علمی لینک‌دار
- 📱 **خروجی برای اپ‌ها** — Hevy، Liftosaur، Lyfta و… با نام دقیق حرکت‌ها از کتابخانهٔ هر اپ + دو پرامپت ChatGPT+Hevy برای ساخت خودکار روتین
- 🔒 **حریم خصوصی کامل** — همهٔ داده‌ها فقط روی دستگاه خودت ذخیره می‌شود

## فناوری

Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · shadcn/ui · Prisma (SQLite) · TanStack Query · Zustand

## اجرا

```bash
bun install
bun run dev        # توسعه — http://localhost:3000
bun run build:static  # خروجی استاتیک برای GitHub Pages
```
